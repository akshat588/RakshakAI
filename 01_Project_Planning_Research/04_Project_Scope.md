# Project Scope

## Overview

RakshakAI is designed as a unified AI-powered cybersecurity platform that detects, analyzes, explains, and assists users against multiple digital threats through a single interface.

The project focuses on combining artificial intelligence, explainable machine learning, and cybersecurity principles to improve digital trust and cyber awareness.

---

# In Scope

The platform will include:

## Threat Detection

- Email Phishing Detection
- URL Security Analysis
- QR Code Threat Detection
- SMS Scam Detection
- WhatsApp Scam Detection
- Fake Job Detection
- UPI Fraud Detection
- Social Engineering Detection

---

## Artificial Intelligence

- Machine Learning Models
- Deep Learning (where applicable)
- Explainable AI (XAI)
- Risk Scoring Engine
- AI Threat Explanation
- AI Cybersecurity Assistant

---

## Knowledge Intelligence

- Retrieval-Augmented Generation (RAG)
- Cybersecurity Knowledge Base
- Threat Intelligence Repository

---

## Dashboard

- Threat Analytics
- Scan History
- User Reports
- Security Insights
- Risk Visualization

---

## Reporting

- PDF Report Generation
- Threat Summary
- Security Recommendations
- Historical Reports

---

# Out of Scope (Version 1)

The following features are intentionally excluded from the first release:

- Real-time Network Intrusion Detection
- Endpoint Antivirus
- Firewall Management
- SIEM Integration
- Cloud Security Monitoring
- Mobile Application
- Browser Extension
- Multi-user Enterprise Management

These may be considered in future versions of RakshakAI.
