# RakshakAI v2 User Manual

## Introduction

RakshakAI is an AI-powered Cyber Fraud Detection and Digital Trust Intelligence Platform designed to analyze suspicious digital content and help users identify potential scams.

---

# Features

- Universal Investigation
- Email Analysis
- URL Analysis
- SMS Scam Detection
- WhatsApp Scam Detection
- UPI Fraud Detection
- QR Code Analysis
- Fake Job Detection
- Social Engineering Detection
- Voice Scam Detection
- AI Investigation Agent
- Threat Intelligence Dashboard
- Case Management
- Report Generation

---

# Getting Started

1. Log in to RakshakAI.
2. Open the Dashboard.
3. Choose an analyzer or use the Universal Investigation page.
4. Submit the suspicious content.
5. Review the investigation results.
6. Save or export the generated report if needed.

---

# AI Investigation Agent

1. Open the AI Investigation Agent.
2. Enter your investigation query.
3. Review the retrieved knowledge, reasoning, and explanation.

---

# Voice Scam Detection

1. Open the Voice Scam Analyzer.
2. Upload a supported audio file.
3. Optionally choose the language or use Auto Detect.
4. Start the analysis.
5. Review the transcript, acoustic analysis, and final decision.
